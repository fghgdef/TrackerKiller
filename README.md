# TrackerKiller 1.0.0-beta

مشروع Android أولي متكامل البنية لحماية الخصوصية، يدعم Shizuku ويتيح اختيار `su` اختيارياً إذا كان الجهاز مروّتاً. لا يتطلب الروت للتشغيل الأساسي.

## الوظائف الموجودة في هذا الإصدار
- لوحة عربية داكنة.
- فحص حالة Shizuku وطلب الإذن.
- فحص اختياري لإمكانية استخدام root عبر `su`.
- اختيار قناة تنفيذ أوامر النظام: Shizuku أو root.
- خدمة VPN محلية لفلترة استعلامات DNS التقليدية IPv4/UDP وفق قائمة نطاقات ثابتة.
- فحص مؤشرات أسماء حزم/مكونات لبعض SDKs التحليل والإعلانات.
- عرض التطبيقات المثبتة، وإتاحة أمر تبديل التجميد/الاستعادة بعد تأكيد المستخدم.
- قراءة وتعديل بعض AppOps من خلال قائمة عمليات محدودة.
- GitHub Actions لبناء Debug APK ونشر Beta prerelease عند التشغيل اليدوي.

## حدود مهمة (اقرأ قبل الاستخدام)
- هذا إصدار Beta تجريبي، وليس منتجاً أمنياً مدققاً. لم يتم إجراء اختبار Gradle أو اختبار على جهاز فعلي في بيئة الإنشاء هذه.
- VPN الحالي ليس جدار حماية شاملاً: يعالج فقط DNS التقليدي IPv4/UDP، ولا يفحص HTTPS/TLS، ولا يمنع DoH/DoT أو الاتصالات بعناوين IP مباشرة، ولا ينسب طلب DNS إلى التطبيق المصدر.
- قائمة النطاقات ثابتة حالياً. إضافة النطاقات المخصصة في واجهة هذا الإصدار تحفظها في حالة الشاشة فقط، ولم تُوصل بعد إلى محرك VPN؛ لا تعتبرها مطبقة على الحظر.
- فحص SDKs يعتمد على مؤشرات أسماء فقط. وجود مكتبة لا يثبت جمع البيانات أو التجسس.
- أوامر AppOps لا تتضمن حتى الآن سجل استعادة موثوقاً للحالة السابقة؛ افحص الوضع قبل أي تغيير ولا تستخدم التعديل على عمليات لا تفهمها.
- تبديل حالة التطبيق يستخدم أوامر package manager وقد يعطل وظائف مهمة. لا تجمّد تطبيقات النظام أو الهاتف أو System UI أو Launcher أو الاتصال أو الطوارئ.
- دعم root اختياري: يحتاج مدير root مثبتاً وموافقة صريحة من نافذة مدير الروت. اختيار root لا يعني أن كل أجهزة Android أو كل عمليات النظام ستسمح بالتعديل.
- بعض الشركات المصنّعة، ومنها واجهات Android المعدلة، قد تقيد أو تغير سلوك VPN وShizuku وAppOps.

## البناء عبر GitHub Actions
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد أو استبدل ملفات مشروعك بها.
2. افتح تبويب Actions وفعّل workflows.
3. شغّل `Build TrackerKiller APK` يدوياً.
4. ستجد Debug APK في Artifacts، كما سينشئ التشغيل اليدوي إصداراً تجريبياً في Releases.

## متطلبات التطوير
- JDK 17
- Android Gradle Plugin 8.7.3
- Gradle 8.9
- Android SDK 35
- Shizuku 13.1.5 (اختياري لعمليات النظام عبر Shizuku)

## أذونات
التطبيق يطلب VPN من Android عبر شاشة موافقة النظام. Shizuku يحتاج تشغيل الخدمة ومنح الإذن للتطبيق. صلاحية root لا تُطلب إلا عند اختيار وضع root وتشغيل أمر يتطلبها.
